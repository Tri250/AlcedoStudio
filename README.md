# 清静 · AiGoodBro

帮助关闭安卓手机里有开关的系统广告、推荐内容、营销通知，以及支持的快应用跳转和广告组件。先检测、再选择，确认后执行，保留备份与还原入口。成功清理后会用默认浏览器打开 https://aigoodbro.com，每轮一次。

**1.0.2 · 1108v3** 已提供 Mac Apple 芯片与 Intel 版、Windows 安装版与便携版、Android arm64 签名版。下载只认本仓库 [Releases](https://github.com/BLACKIELF/qingjing-aigoodbro/releases)。

「超级清静」自动处理已适配的广告项，无需逐项选择。开始前备份，跳过未适配的机型脚本，保留服务通知和受保护组件。

## Mac

- Apple 芯片（M1 及以后），最低系统版本以包内检查结果为准；本版未公证。
- 打开开发者选项与 USB 调试，用能传数据的数据线连接手机，在手机上完成调试授权。
- 检测设备后查看机型适配、选择项目，再开始执行；不要操作手机干扰脚本。
- 系统应用只采用允许的挂起方式；不 root、不解锁、不刷机、不修改系统分区。
- 营销通知、快应用、广告组件有还原入口；App 内的开关按清单手动打开。

## Android

- Android 11 及以上可用内置无线调试配对；Android 8–10 需自行准备已授权的 Shizuku。
- 首次连 Wi-Fi，跟随引导打开开发者选项和无线调试并完成配对。
- 有后台屏支持时可以继续用手机；提示不要碰手机时请等待。
- APK 使用本项目独立签名和应用 ID，可与原版并存。卸载会删除本 App 的备份与授权，不会自动撤销系统改动。

## 范围

- 系统广告、广告跟踪、热榜、负一屏资讯、部分浏览器和商店推广。
- 按通知渠道处理营销信息，保护订单、物流、聊天等服务通知。
- 具体项目依赖机型、系统及机型脚本。第三方 App 自带的开屏广告不在范围内；无关闭开关的内容无法保证消失。
- 不具备 HDC 的原生鸿蒙适配；没有实际手机结果时，不宣称整机去广告验证通过。

## 隐私与反馈

诊断只在本机预览、复制，不向原项目服务器上传。自行提交 GitHub 反馈前请再检查内容。软件内提供开发者「某厂大牛马 · 带娃的小陈工」的抖音主页口令与直达链接，由你主动打开。设备备份保存在本项目独立数据目录，不覆盖原版数据。

## 开源与构建

本项目为 MIT 开源软件的衍生版本。原始项目、作者说明和完整许可可在软件的“关于清静”中查看；源码保留原始 [MIT LICENSE](LICENSE)。

- Mac：`gui/build_mac.sh`（需要 uv、macOS 构建环境）。
- Android：见 [Android 构建说明](android/README.md)；正式签名存于忽略目录或本仓库 Actions Secrets，不提交密钥。
- 设备无关测试：Python 3.13，安装 `requirements.txt`，`npm ci`，`python -m unittest discover -s tests`。

本仓库不承诺每台机型均已验证；构建、桌面界面测试和真机执行分别报告。
