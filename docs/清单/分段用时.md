# 分段用时基线

真机上录到的整轮与分段耗时，集中放在这一页，方便对照「直达改造」（#650 系列）前后的效果、也方便下一轮优化挑最慢的段下手。逐机的录制细节、变体差异与未验证项仍以各机型 README 为准，这里只留数字与出处。

## 记录格式

按机型 README 的既有惯例（#784）：

- 一行一台一轮：**日期 · 通路（电脑经 USB / 无线 adb，或手机本机）· 改前 / 改后（秒）**。
- 分段表：段落名 / 改前 / 改后；没有改前对照的整轮只记总数。
- 录制时中断（adb 掉线、某段没跑）要写明，不全轮的数字不许写成整轮。

## 已知的慢段（下轮优化候选）

- vivo Android 17 变体的**浏览器设置页**没有导出，仍走「右上菜单 → 设置」，电脑上 55 秒，是整轮最慢的一段。
- 小米 M154FF 的**应用商店**改直达后仍有 77 秒，是九段里降幅最小的一段。
- 两台都没在真机上复测过手机版（App 内经 Shizuku）通路的数字；手机本机跑没有电脑侧 adb 往返，理论更快，但无实测。

## 没有基线的部分

- 引擎与机型脚本在本环境（无设备）只能跑设备无关回归，录不了用时；新录入的机时数据以贡献者真机报告为准，收到后并入上表。
